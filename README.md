### 🍽️ [SaaSRestaurante](https://github.com/LoloZaaFernandez/SaaSRestaurante)
SaaS multi-tenant de gestión de restaurantes. Monorepo pnpm + Turborepo: backend Fastify con Screaming Architecture y aislamiento por tenant vía **Row-Level Security en PostgreSQL**, frontend Next.js App Router. Incluye menú digital QR, pedidos, KDS (pantalla de cocina en vivo), pagos (Yape/Plin) y facturación con correlativo boleta/factura.

`TypeScript` `Fastify` `Next.js` `PostgreSQL` `Turborepo` `RLS`

### 🅿️ [Parking-Project](https://github.com/LoloZaaFernandez/Parking-Project)
Sistema de gestión de estacionamiento con **reconocimiento automático de placas (LPR)** en producción. Detección con YOLOv9 + OCR (fast-alpr) sobre cámara IP en tiempo real, votación de placas para evitar falsos positivos, tickets impresos, roles admin/cajero, abonados y reportes.

`Python` `FastAPI` `React` `YOLOv9 / ONNX Runtime` `JWT`

### 🎓 [NormDataUniversidades](https://github.com/LoloZaaFernandez/NormDataUniversidades)
Dataset normalizado de +960 preguntas reales de exámenes de admisión universitaria (UNSA, Perú), construido con un pipeline propio: scraping/OCR, detección automática de preguntas dependientes de figuras, y verificación de claves de respuesta contra solucionarios oficiales.

`Python` `Playwright` `PyMuPDF` `OCR`

### 🏋️ [Frontend_Gym_Cliente](https://github.com/LoloZaaFernandez/Frontend_Gym_Cliente)
App cliente para gimnasios (desktop + Android) construida con **Flet**: seguimiento de membresías con alertas de vencimiento y reportes de pagos por día/semana/mes, empaquetada a APK nativa.

`Python` `Flet`

### ⌨️ [LoloFile](https://github.com/LoloZaaFernandez/LoloFile)
Mi configuración personal de Neovim (**LoloVim**), sobre LazyVim, orientada a mi stack real (Python, React, Next.js, Node): LSP, debugging (DAP) para Python y Node, testing integrado y una variante ultraliviana para hardware limitado.

`Lua` `Neovim`
